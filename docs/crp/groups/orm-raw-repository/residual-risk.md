## 검사하지 않은 것 (범위 밖 명시)

정직한 보고를 위해, 이번 작업이 **확인하지 않은** 것을 적는다.

- **부하·성능**: 커넥션 풀 크기, 큐 로그 처리량, 집계 쿼리의 대용량 실행 계획을 측정하지 않았다.
- **복제 실환경**: `DB_REPLICATION_ENABLED=true` 의 라우팅 판정은 단위 테스트로 검증했으나,
  실제 replica 를 띄워 복제 지연 하에서의 read-after-write 를 관측하지는 않았다.
- **Celery 워커 실행**: 태스크 정의와 세션 컨텍스트는 검사했지만 워커를 기동해 돌리지 않았다.
- **QUICKSTART 2단계의 단일 MySQL `docker run` 경로**: 통합 테스트용 `compose.test.yaml`
  (포트 3308)만 실행 확인했다.
- **Scalar UI 실렌더링**: OpenAPI 문서의 **구조**는 규칙 테스트로 검증했으나, 브라우저에서
  Scalar 가 어떻게 그리는지는 보지 않았다.
