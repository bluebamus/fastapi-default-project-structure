설정·환경변수 레퍼런스

설정 로딩, 검증, 운영 적용과 .env.example의 전체 키를 설명합니다.

설정 로딩 원칙

config.py의 Pydantic Settings가 운영체제 환경변수와 현재 작업 디렉터리의 .env를 타입 검증합니다. .env.example은 복사할 템플릿이지 자동 fallback 파일이 아닙니다. 설정 객체는 캐시되므로 실행 중 파일을 바꿔도 자동으로 다시 읽지 않습니다.

flowchart LR E[OS 환경변수] --> P[Pydantic Settings] F[.env] --> P D[Field 기본값] --> P P --> V[타입/보안 검증] V --> C[캐시된 설정 객체] C --> A[앱·DB·Redis·로그]

각 필드의 소비 지점과 배포 검증은 설정 설계, 기동 시점은 서버 수명주기를 함께 보세요.

운영 적용과 확장

  • 새 설정은 config.py의 알맞은 Settings 클래스와 .env.example를 함께 갱신합니다.
  • 비밀은 저장소에 커밋하지 않고 배포 플랫폼의 secret store로 주입합니다.
  • 필수 여부·기본값·환경별 금지 조합은 validator와 설정 계약 테스트에서 한 번만 강제합니다.
  • DB·Redis·CORS·프록시·로그 설정은 바뀐 소비 지점과 readiness/보안 테스트까지 확인합니다.
코드와 문서가 다르면 코드가 기준입니다. 변경 시 관련 소스·테스트·이 문서를 함께 갱신하세요.
