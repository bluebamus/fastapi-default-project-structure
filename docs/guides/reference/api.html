읽는 법

이 페이지는 실행 중인 FastAPI 애플리케이션의 app.openapi() 결과에서 생성했습니다. 라우터 prefix, HTTP 메서드, operationId, 파라미터, 요청·응답 스키마가 실제 코드와 같은 조립 경로를 거칩니다.

경로 24개, 오퍼레이션 39개, 스키마 38개. OpenAPI의 security 선언은 인증 필요 여부의 한 근거이며, 소유권 검사는 Service 계층에서 추가로 수행될 수 있습니다.

POST /api/v1/auth/login

로그인(OAuth2 password)

username/password(form)로 access·refresh 토큰을 발급합니다. IP+사용자명·IP 단위 레이트 리밋이 걸리고, 성공하면 IP+사용자명 카운터를 지웁니다.

operationId: authLogin · 인증 선언: OpenAPI상 없음 · 요청 본문: Body_authLogin

파라미터위치필수형식설명
없음

응답: 200 Successful Response, 401 인증 실패, 429 시도 횟수 초과 — `Retry-After` 헤더(초) 뒤에 다시 시도, 422 Validation Error

POST /api/v1/auth/refresh

토큰 회전

Refresh Token 을 한 번 쓰고 새 access·refresh 토큰을 발급합니다. 이미 쓴 Refresh Token 을 다시 보내면 그 계열 전체가 폐기됩니다(재사용 탐지).

operationId: authRefresh · 인증 선언: OpenAPI상 없음 · 요청 본문: RefreshRequest
