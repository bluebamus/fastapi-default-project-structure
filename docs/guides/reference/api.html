PROJECT GUIDE

API 레퍼런스

app.openapi() 의 24개 경로·39개 operation 과 뷰마다 선언한 접근 수준입니다.

허브 부팅 설계 API 설정 요청 인증 기능 개발 테스트 운영

도식은 고정 버전 Mermaid CDN을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

공통 규칙

  • 기능 API 는 /api/v1/<기능명>/…, /health·/ready 는 루트입니다.
  • /docs(Scalar)와 /openapi.json 은 DEBUG=true 일 때만 열립니다. 요청·응답 스키마는 그때 확인합니다.
  • /admin(SQLAdmin)은 API 가 아니라 마운트된 하위 앱이며 활성 슈퍼유저 로그인(Redis 서버 세션)으로 들어갑니다. ADMIN_DISABLED=true 면 404 입니다.
  • 오류 본문은 {"error_code", "message", "detail"} 입니다(422 포함). 401 에는 WWW-Authenticate: Bearer, 429 에는 Retry-After 가 붙습니다.
  • 공통 상태: 401 토큰 없음·만료·위조, 403 권한 없음, 404 없음, 409 중복, 422 입력 오류, 429 레이트 리밋, 503 Redis 연결 오류(Redis 를 쓰는 요청만).
  • 레이트 리밋은 register·login 에만 있습니다. PublicWrite 는 "인증 없는 쓰기를 명시적으로 연다"는 선언일 뿐 레이트 리밋을 뜻하지 않습니다.
