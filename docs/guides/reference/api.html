API 레퍼런스

OpenAPI 조립 코드 기준 39개 operation과 접근 정책을 한눈에 정리합니다.

허브부팅설계 API요청인증 기능개발운영

공통 규칙

  • 기능 API는 /api/v1 아래에 있으며 health/readiness는 루트 경로입니다.
  • 입력은 Pydantic 스키마로 검증되고 도메인·저장소 오류는 공통 오류 응답으로 변환됩니다.
  • public-write는 익명 호출을 허용하지만 rate limit과 입력 검증을 생략한다는 뜻이 아닙니다.
  • 정확한 요청·응답 스키마는 실행 중 /docs 또는 /openapi.json에서 확인합니다.
