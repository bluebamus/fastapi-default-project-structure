허브 부팅 설계 API 설정 요청 인증 기능 개발 테스트 운영

도식은 고정 버전 Mermaid CDN을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

기능 경계

  • 각 기능은 app/features/<name> 에 api·services·repositories·models·schemas·dependencies 를 모읍니다.
  • 기능끼리는 import 하지 않습니다. 유일한 예외는 auth 가 user 의 User·UserRepository 를 직접 쓰는 것이고 tests/core/test_layering.py 가 강제합니다. 여러 기능이 쓰는 협력 객체는 app/core 의 provider 로 둡니다.
  • 라우터는 main.py 의 include_router, 관리 화면은 app/features/admin.py 의 명시 import 와 ADMIN_VIEWS 로 등록합니다(기능 admin.py 가 admin_views 를 정의). 모델·태스크는 디렉터리 규칙으로 자동 탐색됩니다.
