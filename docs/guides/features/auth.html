PROJECT GUIDE

API 인증 기능(auth)

가입, 로그인, 토큰 회전, 로그아웃, 현재 사용자 조회를 담당합니다.

허브 부팅 설계 API 설정 요청 인증 기능 개발 테스트 운영

도식은 고정 버전 Mermaid CDN을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

목적과 책임

  • auth 는 모델이 없고 user 기능의 User·UserRepository 를 직접 씁니다(기능 간 import 의 유일한 허용 예외).
  • AuthService 가 PasswordHasher·TokenService·RefreshTokenStore 를 생성자로 받아 직접 부릅니다. 레이트 리밋은 라우트 의존성(login_rate_limit·register_rate_limit)입니다.
  • 가입과 레거시 해시 재저장 로그인만 커밋합니다(핸들러가 service.commit()).
핵심 패턴: JWT + Redis 회전 저장소

API와 접근 수준

메서드경로접근 수준성공추가 검사·주의용도
POST/api/v1/auth/registerPublicWrite201IP 레이트 리밋 429, 사용자명 중복 409회원 가입
POST/api/v1/auth/loginPublicWrite200form 입력. IP+사용자명·IP 레이트 리밋 429, 실패 401access·refresh 토큰 발급
POST/api/v1/auth/refreshPublicWrite200레이트 리밋 없음. 재사용·폐기된 계열 401refresh 토큰 회전
POST/api/v1/auth/logoutPublicWrite204레이트 리밋 없음. 이미 폐기됐어도 204(멱등)토큰 계열(family) 폐기
GET/api/v1/auth/meLoginRequired200DB 에서 사용자를 다시 읽어 삭제·비활성이면 401현재 사용자 조회

트랜잭션 경계: 쓰기 핸들러(View)가 응답 DTO 를 먼저 검증한 뒤 await service.commit() 을 정확히 한 번 부르고 반환합니다. 세션은 의존성(get_writer_db_session)이 열고 닫으며, 커밋 전에 예외가 나면 세션 종료가 롤백합니다. Repository·Dependency 는 커밋하지 않습니다(tests/test_write_dto_before_commit.py, 검수 게이트 INV-2).
