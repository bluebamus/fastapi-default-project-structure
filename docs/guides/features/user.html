PROJECT GUIDE

사용자 기능

사용자 관리, 본인·슈퍼유저 접근 규칙, 변경별 토큰·세션 폐기 규칙을 다룹니다.

허브 부팅 설계 API 설정 요청 인증 기능 개발 테스트 운영

도식은 고정 버전 Mermaid CDN을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

목적과 책임

  • 목록·생성·삭제는 SuperuserRequired, 단건 조회·수정은 로그인 후 Service 가 본인 또는 슈퍼유저만 허용합니다. is_active·is_superuser 변경은 슈퍼유저만 할 수 있습니다.
  • 사용자 변경이 무엇을 폐기하는지는 변경별 폐기 규칙 표 한 곳에 둡니다. 폐기는 커밋 전에 일어나 커밋이 실패해도 폐기된 쪽으로 어긋납니다.
핵심 패턴: 접근 수준 + Service 의 본인 판정

변경별 폐기 규칙

코드 정본: UserService.update_user·delete_user(app/features/user/services/user_service.py). 토큰 쪽 동작은 API JWT 인증, 관리 화면 경로는 관리 화면 인증 안내서 — 폐기 흐름.

변경refresh 토큰 계열관리 세션access 토큰

access 토큰은 폐기 목록이 없어 어느 경우든 만료(기본 15분)까지 발급 시점의 권한을 가집니다.

트랜잭션 경계: 쓰기 핸들러(View)가 응답 DTO 를 먼저 검증한 뒤 await service.commit() 을 정확히 한 번 부르고 반환합니다. 세션은 의존성(get_writer_db_session)이 열고 닫으며, 커밋 전에 예외가 나면 세션 종료가 롤백합니다. Repository·Dependency 는 커밋하지 않습니다(tests/test_write_dto_before_commit.py, 검수 게이트 INV-2).
