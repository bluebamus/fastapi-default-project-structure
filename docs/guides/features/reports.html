매출 보고서 기능

Raw SQL Repository 로 집계 조회와 스냅샷 재적재를 구현한 참조 예제입니다.

허브 부팅 설계 API 설정 요청 인증 기능 개발 테스트 운영

도식은 고정 버전 Mermaid CDN을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

목적과 책임

  • 두 API 모두 SuperuserRequired 입니다.
  • GET /api/v1/reports/sales/daily: read_only 세션에서 sales_orders 원장을 집계합니다.
  • POST /api/v1/reports/sales/daily/snapshots: writer 세션에서 기간의 sales_daily_snapshots 를 DELETE 후 INSERT 로 재적재하고 핸들러가 한 번 커밋합니다(멱등이라 200). 원장은 바꾸지 않습니다.
핵심 패턴: Raw SQL RawRepositoryBase, 조회와 쓰기 경로

트랜잭션 경계: 쓰기 핸들러(View)가 응답 DTO 를 먼저 검증한 뒤 await service.commit() 을 정확히 한 번 부르고 반환합니다. 세션은 의존성(get_writer_db_session)이 열고 닫으며, 커밋 전에 예외가 나면 세션 종료가 롤백합니다. Repository·Dependency 는 커밋하지 않습니다(tests/test_write_dto_before_commit.py, 검수 게이트 INV-2).
