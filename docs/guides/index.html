이 페이지의 역할

구조와 절차의 원본은 Markdown 문서입니다. 저장소 문서 전체의 색인은 README 문서 안내 표 이고, 이 페이지는 그중 HTML 가이드를 브라우저에서 잇는 목차입니다.

  • README — 설치·실행·환경 변수·API·배포 점검
  • ARCHITECTURE — 구조와 런타임 동작의 원본
  • DEVELOPMENT — 기능 개발 절차의 원본

처음 읽기

  • 부팅과 첫 실행 — 설정 검사 → lifespan → readiness → 종료
  • 아키텍처 — include_router 로 명시 조립, 모델·태스크 자동 탐색, 계층 책임
  • API 요청 처리 — 미들웨어 순서, 세션, 트랜잭션, 오류 응답
  • API JWT 인증 — 발급·회전·폐기와 한계
  • 핵심 시퀀스 다이어그램 — 기동·쓰기 트랜잭션·인가

레퍼런스

  • API 레퍼런스 — 전체 operation 과 접근 수준
  • 환경 설정 레퍼런스 — Settings 전 필드와 기동 시 검사

기능별

  • 기능별 안내 — 기능 경계와 등록 방식
  • 접속 로그 기능(home) — ACCESS_LOG_ENABLED 일 때 제외 경로·확장자가 아닌 요청의 접속 정보를 저장하고, 슈퍼유저 조회 API·보존 삭제 태스크를 제공합니다.
  • 블로그 기능 — 게시글 CRUD 와 작성자 기반 수정·삭제 권한의 기준 구현입니다.
  • 댓글 기능 — 댓글 CRUD 와 작성자 기반 수정·삭제 권한을 제공합니다.
  • SNS 기능 — 피드 게시물 CRUD 를 독립 기능으로 제공합니다.
  • 사용자 기능 — 사용자 관리, 본인·슈퍼유저 접근 규칙, 변경별 토큰·세션 폐기 규칙을 다룹니다.
  • API 인증 기능(auth) — 가입, 로그인, 토큰 회전, 로그아웃, 현재 사용자 조회를 담당합니다.
  • 상품 카탈로그 기능 — ORM Repository 로 상품 CRUD 를 구현한 참조 예제입니다.
  • 매출 보고서 기능 — Raw SQL Repository 로 집계 조회와 스냅샷 재적재를 구현한 참조 예제입니다.

개발·테스트·운영

  • 개발 가이드 — 새 기능을 등록하고 검토하는 순서
  • 테스트와 검증 — 로컬·CI 명령과 테스트 층
  • 배포와 운영 — 배포 전 확인, 관측, 장애 대응

흐름 안내서(도식 중심)

  • 관리 화면 인증 안내서 — 세션·CSRF·폐기·운영
