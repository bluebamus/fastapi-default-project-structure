부팅과 첫 실행

설정 준비부터 readiness와 정상 종료까지 실제 기동 경로를 설명합니다.

허브부팅설계 API요청인증 기능개발운영

목적

개발 환경을 재현하고 데이터베이스 스키마를 적용한 뒤 API 프로세스를 안전하게 시작하는 절차입니다. 설정 검증과 외부 자원 연결은 application lifespan 안에서 수행되므로, 단순히 모듈을 import한 상태와 서비스 준비 완료 상태는 다릅니다.

필수 절차

  1. .env.example을 .env로 복사하고 DB·Redis·서명 키를 환경에 맞게 바꿉니다.
  2. uv sync로 잠금 파일 기준 의존성을 설치합니다.
  3. uv run alembic upgrade head로 스키마를 적용합니다.
  4. uv run python main.py로 서버를 실행합니다.
  5. GET /health와 GET /ready를 구분해 확인합니다. readiness 실패는 트래픽을 받으면 안 된다는 뜻입니다.

실패를 읽는 법

  • 설정 오류는 프로세스 시작 전에 고칩니다. 기본값으로 운영 비밀을 대신하지 않습니다.
  • DB 마이그레이션과 애플리케이션 모델이 어긋나면 readiness 또는 요청 시점에 실패할 수 있습니다.
  • Redis는 refresh 토큰, rate limit, 관리자 세션 등에 사용되므로 기능별 장애 범위를 확인합니다.
  • 프로세스 종료 시 새 요청 수락을 멈추고 진행 중 작업과 연결 풀 정리를 기다립니다.
