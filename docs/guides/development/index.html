새 기능 추가

  1. app/features/<name> 안에 기존 기능과 같은 수직 구조를 만듭니다.
  2. 읽기/쓰기 세션, 공개/로그인/관리자 접근 수준, 소유권 규칙을 명시합니다.
  3. 명시적 조립형의 조립 규칙에 맞춰 라우터와 관리자 화면을 등록합니다.
  4. 모델 변경이면 Alembic migration을 만들고 upgrade/downgrade를 검증합니다.
  5. 단위 테스트 후 문서·링크·OpenAPI operation 수를 확인합니다.

코드 리뷰 기준

  • 업무 규칙이 라우터나 저장소로 새지 않았는가
  • 트랜잭션의 commit/rollback 소유자가 하나인가
  • 인증 실패, 권한 실패, 없음, 충돌이 일관된 오류 계약을 따르는가
  • 비동기 함수 안에 블로킹 I/O가 추가되지 않았는가
  • 새 공개 API와 설정이 문서화되었는가
