CODE-VERIFIED GUIDE

배포와 운영

설정, migration, readiness, 관측, 정상 종료를 연결한 운영 체크리스트입니다.

허브부팅설계 API요청인증 기능개발운영

배포 전 필수 확인

  • 운영용 DB·Redis URL과 충분히 긴 서명 키를 비밀 저장소에서 주입합니다.
  • debug와 불필요한 관리자 기능을 끄고 CORS·trusted proxy 범위를 실제 인프라에 맞춥니다.
  • alembic upgrade head를 애플리케이션 rollout과 호환되는 순서로 실행합니다.
  • 웹 프로세스와 Celery worker/beat의 설정·코드 버전을 맞춥니다.
  • /health는 생존, /ready는 트래픽 수신 가능 여부에 사용합니다.

운영 관측과 장애 대응

  • request id를 기준으로 접근 로그와 예외 로그를 연결합니다.
  • 5xx 증가, readiness 실패, DB pool 고갈, Redis 오류, task 적체를 알림 대상으로 둡니다.
  • DB/Redis 장애 시 기능별 영향 범위를 확인하고, 인증 저장소 오류를 무조건 허용으로 우회하지 않습니다.
  • 종료 grace 기간은 실제 가장 긴 정상 요청과 background 정리 시간을 근거로 정합니다.
