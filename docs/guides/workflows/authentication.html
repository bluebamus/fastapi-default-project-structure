인가와 소유권

공개·로그인·슈퍼유저 수준은 route dependency로 선언되어 누락을 기동 시 검사합니다. 특정 게시물의 작성자인지는 입력 스키마의 user id를 믿지 않고 인증된 Principal과 저장된 owner id를 Service의 OwnershipPolicy가 비교합니다.

401은 인증 실패, 403은 인증됐지만 권한 부족입니다. 숨겨야 하는 리소스의 존재 여부 정책은 Service에서 일관되게 정합니다.
