PROJECT GUIDE

핵심 시퀀스 다이어그램

기동·종료, 쓰기 트랜잭션, 인증·인가의 상호작용을 한곳에 모았습니다.

허브 부팅 설계 API 설정 요청 인증 기능 개발 테스트 운영

도식은 고정 버전 Mermaid CDN을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

쓰기 유스케이스

sequenceDiagram participant C as Client participant D as 의존성 participant V as View participant S as Service participant R as Repository participant W as writer 세션 C->>D: POST, PATCH, DELETE D->>W: get_writer_db_session 이 세션을 연다 D->>S: Service 조립 D->>V: 접근 수준 통과, 주입 V->>S: 유스케이스 호출 S->>R: 변경 R->>W: flush V->>V: 응답 DTO 검증 V->>S: await service.commit() S->>W: commit 1회 V-->>C: 201, 200, 204 Note over D,W: 커밋 전 예외면 세션 종료가 rollback 한다

쓰기 핸들러(View)가 응답 DTO 를 먼저 검증한 뒤 await service.commit() 을 정확히 한 번 부르고 반환합니다. 세션은 의존성(get_writer_db_session)이 열고 닫으며, 커밋 전에 예외가 나면 세션 종료가 롤백합니다. Repository·Dependency 는 커밋하지 않습니다(tests/test_write_dto_before_commit.py, 검수 게이트 INV-2).
