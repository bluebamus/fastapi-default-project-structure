설계 의도

main.py가 라우터, 미들웨어, 관리자 화면을 명시적으로 조립합니다. 실행 순서가 한 파일에 드러나므로 추적과 디버깅이 단순합니다.

기능은 app/features/<name> 아래에서 API, 서비스, 저장소, 모델, 스키마를 함께 소유합니다. 공통 인프라만 app/core로 올려 기능 간 결합을 줄입니다.

라우터는 HTTP 변환과 의존성 선언, 서비스는 유스케이스와 트랜잭션 경계, 저장소는 영속성 세부사항을 담당합니다. 저장소가 HTTP 예외를 만들거나 라우터가 직접 쿼리를 조합하지 않는 것이 핵심입니다.
